# 考卷

这里放**公开的基线自测**。目的只有一个：把"我觉得我懂了"变成一个能对比的数字。

## 为什么要公开这个

学一个陌生的系统，最危险的时刻是"每个词都有印象、都觉得懂，但让你解释就不知道从哪说起"。这种状态下读得越多，错觉越强——因为 AI 的输出被优化成读起来顺，而"读起来顺"恰好会被误认成"我懂了"。

对抗它的办法不是再读一遍，是**先答一次，留下证据，过一段时间再答一次，看差在哪**。

公开这一份，是因为：分数可以私藏，错在哪没法伪造。别人抄得走结论，抄不走你答错的痕迹。

## 怎么用

1. 你也想自测，就先自己答一遍再往下看——**不查资料**。
2. 看完我的作答，别急着认同或否定，先问自己"我会不会也是这么答的"。
3. 六个月后我会重考同一套题，diff 直接提交在 `exam/` 下。**到时能看出这套学习路线到底有没有用。**
