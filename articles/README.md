## 约定

1. **锁定 commit。** 引源码一律用 permalink（`blob/<commit>/path#Lx-Ly`），不用 `master`。行号会漂，commit 不会。
2. **开头三行给结论。** 读者不该为了知道结论读两千字。
3. **结尾一段差异。** 和另一个实现（Hermes、Codex、LangGraph、别的 harness）哪里不一样——**只在不一样的地方停下来想**。
4. **写完补《我先前的错误理解》。** 见 [模板](_template.md)。这一节编不出来，只能真的错过。

按“有人会搜”的程度排，不按我读到的顺序排：

- 授权（Mandate）为什么必须是结构化数据，不能写进提示词
- 失败之后靠什么恢复：SQLite 里是哪几张表，重放怎么保证不重复
- 一个工单跑完，结果怎么保证落回原会话而不是开新线程
- 主动模式（observe）为什么先只记录不动手
- 什么情况下不该用这套架构（单仓库小项目、单人使用）
